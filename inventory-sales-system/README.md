# نظام إدارة المخزون والمبيعات - بصمة للسوفت وير

نظام ويب متكامل لإدارة المخزون والمبيعات موجه لأصحاب المحلات الصغيرة والمتوسطة في السوق العربي والمصري بشكل خاص.

## نظرة عامة
هذا النظام يوفر:
- **نقطة بيع (POS)** لإصدار الفواتير瞬اناً
- **إدارة المخزون** مع تنبيهات عند انخفاض الكميات
- **إدارة العملاء** مع تتبع الأرصدة (مدين/دائن)
- **التقارير والإحصائيات** للمبيعات اليومية والأكثر مبيعاً
- **طباعة الفواتير PDF** باللغة العربية والجنيه المصري
- **فترة تجريبية مجانية 60 يوماً** للعملاء الجدد

## التشغيل السريع (التطوير)

### الخادم الخلفي (باك إند)
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
flask init-db
flask run --host=0.0.0.0 --port=5000
```

### الواجهة الأمامية (فرونت إند)
```bash
cd frontend
npm install
npm run dev
```

### عبر دوكير (الكل في واحد)
```bash
docker-compose up --build
```

## الميزات الخاصة بالسوق المصري
- واجهة باللغة العربية واتجاه RTL
- عملة الجنيه المصري (EGP) مع تنسيق الأرقام العربية-الهندية
- ضريبة القيمة المضافة 14% قابلة للتعديل
- تاريخ بالتنسيق DD/MM/YYYY
- دعم printing الفاتورة PDF مع تفاصيل المتجر

## خريطة الطريق القادمة
1. الربط مع نظام الفاتورة الإلكترونية المصري (ETA) عبر واجهة JSON/XML
2. تطبيق جوال لنقطة البيع يعمل بدون إنترنت (Offline POS)
3. تكامل مع بوابات الدفع المصرية (فوري، إنستا باي، فودافون كاش)
4. تقارير ضريبية شهرية وربع سنوية مهيأة للإقرار الضريبي

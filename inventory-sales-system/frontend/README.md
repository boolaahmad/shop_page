# واجهة المستخدم - نظام إدارة المخزون والمبيعات (Frontend)

واجهة ويب بلغة عربية واتجاه RTL لنظام إدارة المخزون والمبيعات الموجه للسوق المصري.

## تقنيات التشغيل
- React 18 + Vite
- Tailwind CSS
- React Router DOM
- Axios (استدعاءات API)
- TanStack React Query (إدارة حالة الخادم)
- React Hook Form + Zod (نماذج وتحقق) — في صفحات المبيعات والمنتجات
- Lucide React (الأيقونات)
- react-hot-toast (التنبيهات)
- i18next (الدعم متعدد اللغات)

## التشغيل السريع

```bash
cd frontend

# تثبيت الحزم
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء للإنتاج
npm run build
```

سيفتح التطبيق على المنفذ `http://localhost:5173` ويتصل بالخادم الخلفي على `http://localhost:5000` عبر وكيل Vite.

## هيكل المجلدات
```
src/
  components/   # مكونات مشتركة (التخطيط، الشريط الجانبي، الشريط العلوي)
  hooks/        # هوكات مخصصة (useAuth)
  lib/          # إعدادات Axios وأدوات التنسيق (العملة والتاريخ)
  pages/        # صفحات التطبيق (تسجيل الدخول، لوحة التحكم، المنتجات، نقطة البيع، العملاء، التقارير، الإعدادات)
```

## تنسيق العملة والتاريخ
- يتم استخدام `Intl.NumberFormat('ar-EG')` لتنسيق الجنيه المصري (EGP) مع فاصل الآلاف والكسور بالعربية.
- التواريخ تعرض بالتنسيق `DD/MM/YYYY` وفقًا للغة العربية.
